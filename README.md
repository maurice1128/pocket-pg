# 口袋控衛 Pocket PG

控衛閱讀訓練原型：第一人稱看防守反應，做出投、傳、切的決定，記錄決策時間。題目依教科書撰寫，包含快攻、切入分球、撲防、沒有優勢時轉移球、後門、擋拆，以及打到出手才結束的連續回合。

- 線上試玩：https://maurice1128.github.io/pocket-pg/
- 操作：按一下＝投、長按＝切、往隊友滑＝傳（右下角也有「投」「切」按鈕，可在首頁關掉）。
- 直拿手機就可以玩；橫拿視野比較寬。第一次會先做 5 次反應時間校準。
- 「轉頭模式」需要陀螺儀，iPhone 會先詢問權限；請用 Safari／Chrome 開啟（LINE 等 App 內建瀏覽器不給權限）。
- 答案為初版：已對照教科書並經獨立引用查核，尚待教練審核。
